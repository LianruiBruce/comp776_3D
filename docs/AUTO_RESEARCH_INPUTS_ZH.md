# 下一批 likeness 数据怎样交给分析程序

**当前示例全是 `SIMULATION_ONLY` 教学数据，没有任何新参与者或本人评分。** 示例和演示结果位于 `artifacts/runs/20260905_auto_research/simulation/`。

准备真实数据前，先落实研究同意和适用审批。不要把 FEI 自动结果填成“本人评分”。

每份输入是由记录组成的 JSON 数组：

| 名称 | 要记录什么 |
|---|---|
| `identities` | 匿名身份、开发/确认划分、本人唯一评分者 ID、是否仍同意分析 |
| `photos` | 每人八张：输入 1、图库 3、真实中性 2、真实微笑 2；样本 ID、来源 hash、照片角色 |
| `candidates` | 真实/生成候选、身份、模型、表情、重复编号、图像 hash；生成失败也保留一行 |
| `raters` | 评分者唯一 ID，以及其认识的身份；同一个人不可换 ID 重复计数 |
| `assignments` | 预先安排的候选—评分者配对，含候选 hash、本人与陌生人分组 |
| `responses` | 配对 ID、1—7 整数分，或 `unjudgeable`/`missing` 加空分数 |

调用 `id_layers.likeness_study.analyze_likeness_study(...)`。程序先校验重复、身份交叉和错误配对，再分别分析本人和陌生人。

每格先平均候选，再按身份等权：`D=[(R0−G0)+(R1−G1)]/2`；`E=(R1−G1)−(R0−G0)`。正 D 表示生成较不像，正 E 表示微笑额外缺口。缺失不算零；四格至少各有一张有效候选才计算该身份的 D/E，同时给出数量、完整候选敏感性和缺失界限。没有生成出图像的失败另计，不能补一个 likeness 分数。

本人使用身份均值 t 区间及 bootstrap 敏感性；陌生人保留跨身份评分者关系，给出交叉重采样敏感性。正式有序/混合模型及多重比较规则仍需在真实确认评分前冻结。模拟功效不能代替真实预试验方差，也不能决定最终人数。

交叉重采样借鉴分别抽样身份与评分者的思路；不是对当前缺失规则和小样本 D/E 的精确覆盖保证。[Owen，2007](https://arxiv.org/abs/0712.1111)
