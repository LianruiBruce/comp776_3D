# Curated reports

This directory contains compact, versionable interpretations of immutable run artifacts. Each report must name the exact run ID and avoid copying restricted face images.

- `SMOKE_FEI_LVFACE_T.md`: aligned neutral/smile pipeline validation.
- `E1_FEI_FULL_LVFACE_T.md`: full FEI pose/expression/illumination layer sweep.
- `E2_FEI_FULL_LVFACE_PROBES.md`: equal-capacity five-seed readouts and the frozen selected-versus-final test.
- `GENERATION_IDENTITY_PILOT.md`: PhotoMaker V2 eight-identity automatic channel/reference diagnostic; the human-perception portion remains pending.

Generation reports may include aggregate metrics and non-identifying figures only. Do not copy FEI references, generated faces, blinded-evaluation media, participant responses or an answer key from `artifacts/runs/` into this directory. Automatic recognizer scores must not be worded as human likeness preferences.
